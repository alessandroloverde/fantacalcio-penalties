🔄 Migrate Participant IDs to Auth UIDs

⚠️ Instructions:

  1. Create Auth users manually in Firebase Console (Authentication)
  2. Copy each user's UID (click "Copy UID" option)
  3. Go to Firestore and find the corresponding participant document
  4. Enter the mapping below: one line per user in format: oldParticipantId → authUID
  5. Review the preview, then execute
